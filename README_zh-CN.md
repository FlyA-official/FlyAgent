## Zero零牌谱 · 纯自对弈强化学习训练

要超越人类，就不能以人类的思路去引导训练。FlyA Manout 不使用人类牌谱数据，采用非完美信息博弈领域最有纳什均衡收敛保障的反事实遗憾最小化算法，从 0 开始自对弈，自发涌现出顶级牌力。同时也提供顶尖人类数据集蒸馏的 Heyman 系列模型，以及在 Heyman 基础上强化的 Manplus 模型，更有助于新手的理解与学习。

- **反事实遗憾最小化 · Manout 用的**：有纳什均衡收敛保障，稳稳落在最不容易被对手针对的那个配比上。
- **PPO 等策略梯度**：每一步都在针对上一步的自己，追着自己的影子绕圈，离最优配比始终差一截，永远收敛不到。

**Manout 的 Zero 式训练同样能涌现出人类高手才会熟练使用的技巧，例如：**

- **配牌不好，早早留安** — 不是等到有人立直才开始找安全牌，是开局就认清这把打不了，先定下防守基调。
- **大幅领先时全弃电报** — 为了守住顺位主动放弃这一局。这是分数意识，不是牌力计算。
- **大量反直觉的逆牌效** — 牌效上算亏，但综合胜率更高——很多是以前没人这么打过的。

## 常见问题

**会不会被封号？**

FlyAgent 不篡改对局数据，也不获取任何你本来看不到的信息——它读到的和你屏幕上看到的完全一致。

请在各平台规则允许的范围内合规使用。

**需要注册账号吗？**

不需要。买一枚 Key 填进软件就能用，不要手机号，不要邮箱，不绑定任何账号。

**支持什么系统？**

Windows 已支持；macOS、Android 开发中；Linux、iOS 计划中。

**一枚 Key 能在几台设备上用？**

同时只能一台。换设备登录会把上一台顶下来，上一台会立刻收到通知。如果不是本人操作，可以在那台设备上顶号登回，或直接冻结这枚 Key：冻结后所有设备立即退出，这枚 Key 永久失效、无法恢复，需联系客服更换。

**我的牌局数据会被上传吗？**

推理在云端完成，所以当前这一手的牌局信息需要发到服务器才能算出推荐——这是它能给出建议的前提。

但对局记录只保存在你自己电脑上，不会上传；软件里也没有任何使用统计或行为埋点。

**解压后 Windows 提示不安全？**

压缩包还没有做数字签名，首次运行 Windows 会弹 SmartScreen 提示，选择「仍要运行」即可。签名会在正式发布前补上。

**怎么更新？**

软件会在后台检查新版本，发现新版本只会点亮一个更新按钮。要不要更新由你决定。每次下载都会做完整校验，校验不过就不会运行。

**怎么卸载？**

直接删掉解压出来的文件夹即可，没有卸载程序、不留残留。证书可以在应用内一键移除。
