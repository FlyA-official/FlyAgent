## Zero零牌譜 · 純自對弈強化學習訓練

要超越人類，就不能以人類的思路去引導訓練。FlyA Manout 不使用人類牌譜數據，採用非完美資訊博弈領域最有納許均衡收斂保障的反事實遺憾最小化演算法，從 0 開始自對弈，自發湧現出頂級牌力。同時也提供頂尖人類數據集蒸餾的 Heyman 系列模型，以及在 Heyman 基礎上強化的 Manplus 模型，更有助於新手的理解與學習。

- **反事實遺憾最小化 · Manout 用的**：有納許均衡收斂保障，穩穩落在最不容易被對手針對的那個配比上。
- **PPO 等策略梯度**：每一步都在針對上一步的自己，追著自己的影子繞圈，離最優配比始終差一截，永遠收斂不到。

**Manout 的 Zero 式訓練同樣能湧現出人類高手才會熟練使用的技巧，例如：**

- **配牌不好，早早留安** — 不是等到有人立直才開始找安全牌，是開局就認清這把打不了，先定下防守基調。
- **大幅領先時全棄，甚至故意放銃** — 為了守住順位主動放棄這一局。這是分數意識，不是牌力計算。
- **大量反直覺的逆牌效** — 牌效上算虧，但綜合勝率更高——很多是以前沒人這樣打過的。

## 常見問題

**會不會被封號？**

FlyAgent 不竄改對局資料，也不取得任何你本來看不到的資訊——它讀到的和你螢幕上看到的完全一致。

請在各平台規則允許的範圍內合規使用。

**需要註冊帳號嗎？**

不需要。買一枚 Key 填進軟體就能用，不要手機號，不要信箱，不綁定任何帳號。

**支援什麼系統？**

Windows 已支援；macOS、Android 開發中；Linux、iOS 規劃中。

**一枚 Key 能在幾台裝置上用？**

同時只能一台。換裝置登入會讓上一台登出，上一台會立刻收到通知。如果不是本人操作，可以在那台裝置上頂號登回，或直接凍結這枚 Key：凍結後所有裝置立即登出，這枚 Key 永久失效、無法恢復，需聯絡客服更換。

**我的牌局資料會被上傳嗎？**

推理在雲端完成，所以目前這一手的牌局資訊需要傳到伺服器才能算出推薦——這是它能給出建議的前提。

但對局記錄只保存在你自己電腦上，不會上傳；軟體裡也沒有任何使用統計或行為埋點。

**解壓後 Windows 提示不安全？**

壓縮包還沒有做數位簽章，首次執行 Windows 會跳出 SmartScreen 提示，選擇「仍要執行」即可。簽章會在正式發佈前補上。

**怎麼更新？**

軟體會在背景檢查新版本，發現新版本只會點亮一個更新按鈕。要不要更新由你決定。每次下載都會做完整驗證，驗證不過就不會執行。

**怎麼解除安裝？**

直接刪掉解壓出來的資料夾即可，沒有解除安裝程式、不留殘留。憑證可以在應用程式內一鍵移除。
