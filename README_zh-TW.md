## 零人類牌譜 · 自我對弈強化訓練

FlyA 模型做到**完全不使用任何人類牌譜**，採用非完美資訊博弈領域中最具納許均衡收斂保證的「反事實遺憾最小化」演算法，從 0 開始自我對弈，自發湧現出頂級牌力。

我們走過三條路，也看清了它們的區別：

| 方法 | 結果 |
|---|---|
| **反事實遺憾最小化（CFR）** · FlyA 採用的 | 有納許均衡收斂保證，穩穩落在**最不容易被對手針對**的那個配比上 |
| PPO 等策略梯度 | 衝向極端去針對對手，又被對手針對回來，繞著最佳配比一圈圈打轉，始終停不下來 |
| DQN 等價值函數方法（如 Mortal） | 練到某個點之後策略崩潰、退化，縮在角落裡只會一種打法 |

**Zero 式訓練同樣能湧現出人類高手才會熟練使用的技巧：**

- **配牌不好，早早留安** — 不是等到有人立直才開始找安全牌，是開局就認清這把打不了，先定下防守基調
- **大幅領先時全棄電報** — 為了守住順位主動放棄這一局。這是分數意識，不是牌力計算
- **大量反直覺的逆牌效** — 牌效上算虧，但綜合勝率更高——很多是以前沒人這樣打過的

> 訓練方法與取捨，見官網文章《[FlyA 設計哲學](https://nashout.com/articles/flya-design-philosophy)》。

## 局內教學 · 極速且豐富的推理輸出

**全球節點**：全球部署，極低的推理延遲。

- **候選** — 混合策略輸出，候選機率越接近，說明動作影響越接近

- **模型動機** — 展示當前策略下的模型動機

## 開始使用

三步就能收到第一則推薦：

1. **下載並解壓縮** — 綠色可攜版，解壓縮到任意資料夾即可，不需要安裝，也不需要管理員權限。首次執行 Windows 可能彈出 SmartScreen 提示（壓縮檔還沒做數位簽章），選擇「仍要執行」。

## 常見問題

**會不會被封鎖帳號？**
FlyAgent 不竄改對局資料，也不取得任何你本來看不到的資訊——它讀到的和你螢幕上看到的完全一致。請在各平台規則允許的範圍內合規使用。

**需要註冊帳號嗎？**
不需要。買一組 Key 填進軟體就能用，不要手機號碼，不要電子信箱，不綁定任何帳號。

**一組 Key 能在幾台裝置上用？**
同時只能一台。換裝置登入會把上一台頂下來，上一台會立刻收到通知，可以確認是不是本人操作。

**我的牌局資料會被上傳嗎？**
推理在雲端完成，所以當前這一手的牌局資訊需要送到伺服器才能算出推薦——這是它能給出建議的前提。但對局記錄只儲存在你自己的電腦上，不會上傳；軟體裡也沒有任何使用統計或行為追蹤。

**解壓縮後 Windows 提示不安全？**
壓縮檔還沒做數位簽章，首次執行 Windows 會彈出 SmartScreen 提示，選擇「仍要執行」即可。簽章會在正式發布前補上。

## 安全邊界

- **只用看得見的資訊** — 它處理的是牌桌上本來就看得見的東西：自己的手牌與副露、牌河、公開的立直與寶牌、自己的摸牌鳴牌。**不取得牌山、對手手牌、他人暗槓或任何伺服器端私有資料**。
- **無作弊能力** — 不讀取或修改遊戲記憶體、不注入遊戲行程、不竄改遊戲檔案、不利用任何漏洞。
- **記錄只在本機** — 對局記錄、憑證、設定全在程式自己的目錄裡，**刪掉資料夾就等於解除安裝**。
- **是否允許輔助工具由各平台規則決定** — 請在使用前自行了解並遵守對應平台的規則。
