## Zero・牌譜ゼロ · 純粋な自己対戦による強化学習

人間を超えるには、人間の発想で学習を誘導してはいけません。FlyA Manout は人間の牌譜データを使わず、不完全情報ゲームの分野で最も強力なナッシュ均衡への収束保証を持つ反実仮想後悔最小化アルゴリズムで 0 から自己対戦を重ね、トップクラスの牌力が自発的に創発しました。あわせて、トップ層の人間データセットから蒸留した Heyman シリーズと、Heyman をベースに強化した Manplus も提供しており、初心者にとって理解しやすく学びやすいモデルです。

- **反実仮想後悔最小化 · Manout が採用**：ナッシュ均衡への収束が保証されており、相手に最も狙われにくい配分に確実に収まります。
- **PPO などの方策勾配法**：一手ごとに直前の自分を狙い返すため、自分の影を追ってぐるぐる回り、最適な配分から常に少しずれたまま収束しません。

**Manout の Zero 式の学習でも、人間の上級者しか使いこなせない技術が創発します。たとえば：**

- **配牌が悪いと、早めに安牌を残す** — 誰かがリーチしてから安全牌を探し始めるのではなく、配牌の時点でこの局は攻められないと見切り、守りの構えを決めます。
- **大きくリードしたら全降り、時には差し込み** — 順位を守るために、その局を自ら捨てる。これは点数の感覚であって、牌力の計算ではありません。
- **直感に反する逆牌効率を次々と打つ** — 牌効率だけ見れば損ですが、総合的な勝率は高い——これまで誰も打たなかった手が少なくありません。

![FlyAgent の推薦カード：高速で豊富な推論出力](images/reco.webp)

- **グローバルノード** — 世界各地に配置し、推論レイテンシを低く抑えます

## よくある質問

**アカウント停止になりますか？**

FlyAgent は対局データを改ざんせず、本来あなたが見られない情報を取得することもありません——読んでいるのは、画面に映っているものとまったく同じ情報です。

各プラットフォームの規約が認める範囲内でご利用ください。

**アカウント登録は必要ですか？**

不要です。Key を1枚購入してソフトウェアに入力するだけ。電話番号もメールアドレスも不要で、アカウントと紐づける必要もありません。

**対応 OS は？**

Windows は対応済みです。macOS と Android は開発中、Linux と iOS は計画中です。

**1枚の Key は何台のデバイスで使えますか？**

同時に使えるのは1台だけです。別のデバイスでログインすると前のデバイスはログアウトされ、すぐに通知が届きます。本人の操作でない場合は、そのデバイスから再ログインして取り戻すか、この Key を凍結できます。凍結するとすべてのデバイスが直ちにログアウトされ、Key は永久に使えなくなり元に戻せません。交換はサポートまでご連絡ください。

**対局データはアップロードされますか？**

推論はクラウドで行われるため、今の一手の対局情報をサーバーに送って初めて推奨を計算できます——それが提案を実現する前提です。

ただし対局記録はあなたの PC 上にのみ保存され、アップロードされません。ソフトウェア内に利用統計や行動トラッキングも一切ありません。

**解凍後に Windows が安全性の警告を出すのはなぜ？**

アーカイブはまだデジタル署名されていません。初回起動時に Windows の SmartScreen が表示されることがありますが、「実行」を選んでください。署名は正式リリース前に追加します。

**アップデートの方法は？**

ソフトウェアはバックグラウンドで新しいバージョンを確認し、見つかると更新ボタンを表示するだけです。更新するかはあなた次第。ダウンロードは常に検証され、検証に失敗した場合は決して実行されません。

**アンインストールの方法は？**

解凍したフォルダーを削除するだけです。アンインストーラーはなく、残留物もありません。証明書はアプリ内でワンクリックで削除できます。
